# Sum up 24 November 2026 world news in one image

Entry for make.fun bounty `news-image-20261124`.

`main.py` writes `/output/entry.png`, 1024x1024, PNG, deterministic,
stdlib only. It draws a header "24 NOVEMBER 2026 — WORLD NEWS IN ONE IMAGE"
and six headlines: COP31 collapse, Russian warship off Libya, Nvidia
reappoints Jensen Huang, Bangladesh typhoid vaccination, Himalayan flood
in India, Vanuatu earthquake.

Run: `python3 main.py`
